# CEU — instruções de trabalho

As instruções para agentes e contribuidores estão em [AGENTS.md](AGENTS.md). Este arquivo permanece como ponto de entrada para ferramentas que procuram `CLAUDE.md`; mantenha os dois documentos coerentes quando os comandos, a arquitetura ou o workflow de release mudarem.

A identidade oficial do projeto é **CEU — Composable Experimentation Unit**. Caminhos locais, credenciais, tokens, bancos, logs e configurações específicas de uma máquina não pertencem ao repositório.
